# colab-regression
Apartment price prediction using linear regression
In this project, I use linear regression to predict apartment prices based on their area.

Dataset

I use a CSV file with apartment areas and prices.

area_m2: Apartment area in square meters

price_thousands_pln: Apartment price in thousands of PLN

What I Did

Loaded the data using pandas

Created a linear regression model

Made a graph

Compared linear and polynomial regression

Calculated MAE and RMSE

Files

colab_regression (1).ipynb: My Python notebook

apartments.csv: The data

regression (1).png: The graph

Result

The model predicts apartment prices based on their area. I also compared the errors of two models.
